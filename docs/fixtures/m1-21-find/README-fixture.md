## Pure/model expectations for workers

The find index is built from the immutable `MarkdownRenderDocument` arena only: leaves in `leafIDs` order, including table cells, code blocks, headings, quoted/list/footnote paragraphs and the `.metadata` leaf; never the source string, never container chrome (list markers, alert labels, footnote ordinals, quote depth captions, the metadata explanation line), never link destinations, image sources or hidden comments (which #15 already removes from `block.text` by token provenance). Image runs are excluded so an image's alt text is not reported as visible prose. Matches never span two leaves, two metadata rows or a metadata key/value separator. Match ranges are UTF-16 offsets in `String(block.text.characters)`; native leaves map them to display ranges through `MarkdownCellDisplayProjection.displayRange(for:)` and SwiftUI leaves through `AttributedString.utf16` indices. Table cell addresses are presentation-lifetime and are re-derived from the new arena after any refresh.

Cursor arithmetic is pure: next/previous over the ordered match list, wrapping by default, with an explicit wrapped flag; an empty or whitespace-only query has no matches and no "not found" state; a non-empty query with zero matches is the not-found state.
