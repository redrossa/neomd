## Pure/model expectations for workers

Every structured table owns row/column/header/alignment information and one attributed leaf per cell, including empty/comment-only/anchor-only cells. Header-only empty table remains a table. Cells stay row-major and distinct even with identical text/header labels. Inline task-looking text remains literal while real enclosing task state is preserved. Hidden comment text does not enter cell payload or AX/display projection; code syntax examples stay literal. Existing inline image occurrence, link/cue and generated-footnote attributes must survive. Do not replace all text with a tab/newline string or recursively own MarkdownBlocks.

`comparison.md` intended notable payloads: ` x ` in its all-code boundary cell; `a|b` in the escaped code-pipe cell; subscript 2 and superscript 3; `under` underlined; color reference #12AB34 retains code text plus cue attribute; known shortcode transforms through existing corpus while unknown stays literal; `beforeafter` without TABLE_SECRET; `[ ] literal` and `[x] literal` are not task state. Header styling is additive, not destructive of attributed runs.

`contexts.md` intended targets: `empty-cell` points to its empty cell, not next neighbor; two note references return to their own cells, not the table start; authored `fn-same` collision never steals the generated note destination. Metadata remains separate `.metadata` content. Local image source is resolved against this directory; adjacent same-URL occurrences remain distinct, empty alt keeps its semantic carrier and displayed Image label, missing image keeps meaningful fallback. No inline `<picture>` extension is implied.
