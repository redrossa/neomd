## Reading context before checkpoint

Paragraph 01. Source context must survive additional-reader acquisition. Selectable prose is not an app control.

Paragraph 02. The destination can already be visible in another reader without changing this reader's selected passage.

Paragraph 03. A failed or missing target must leave this paragraph available and preserve the current presentation.

Paragraph 04. Relative links use this source's own folder. The leading slash deliberately does not mean a repository root.

Paragraph 05. Internal anchors remain source navigation even when a Command modifier is held for a click.

Paragraph 06. Keyboard and contextual Open Link are ordinary activations; this fixture does not request additional keyboard commands.

Paragraph 07. Keep ordinary underlines, native pointing-hand link regions and text selection behavior.

Paragraph 08. No document content in this packet contains an executable command or automatic browser action.

Paragraph 09. A linked image and its unavailable fallback use the same destination semantics as ordinary text links.

Paragraph 10. Unlinked image-only leaves remain image content without a link action.
