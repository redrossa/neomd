## Plan mapping and invariants

1. `MarkdownRenderDocument` owns immutable node records with scalar parent/child IDs, preorder subtree intervals, leaf IDs, first/last leaf, lazy-root and anchor indexes. Records never own other records/document handles. `CMarkBlockAdapter.materialize` directly remaps final drafts rather than rebuilding recursive values. Existing parser discovery, allocation and lock are unchanged.
2. `MarkdownBlockRenderer.render` returns one snapshot. `DocumentReaderView` publishes that complete generation and performs direct ID lookups for keyboard destinations. Cancellation discards the completed snapshot safely. Existing model tests now use document-aware child/leaf queries; their payload/ID/reference expectations remain substantive.
3. `RenderLifecycle` is an unhosted test-only Xcode scheme compiling the actual synchronized rendering sources and the same local parser package. `Scripts/test-render-lifecycle.py` builds once and selects a single method/depth per process, rejecting zero tests, skips, failed exits, known restart diagnostics and missing post-release completion. It first proves rejection of an intentional assertion failure. No production runtime test flags or signing/sandbox changes.
4. `MarkdownContainerGeometry` performs bounded preorder/reverse/placement passes with scalar arrays. `MarkdownContainerLayout` places sibling native leaves and markers; `MarkdownContainerView` preserves leaf identity across width changes. Numeric tests cover ordinary 15pt quote / 36pt marker increments, direct-list −14 adjustment, baselines, continuation spacing and branching operation bounds. Native code/link/focus implementations and navigation bridge are retained.
5. Compression uses actual content width W, minimum text R=min(240,0.60W), budget B=W−R, and activates only when natural structural inset exceeds B. Quote rules project inside that budget; homogeneous unary compressed quote runs receive a passive exact-depth caption. Task/ordinal contexts get source-ordered rows, not overlapping tiny glyphs. Shallow siblings stay ordinary. No explorer, popover, depth cap or structural horizontal scroller.
6. Final native coverage passes: eleven preservation methods plus deep actual-file and mixed actual-file tests; three host/registry methods also pass individually. Native bridge negative ownership/cancellation/cleanup tests remain unchanged. The sole manual speech check is deferred under the linked user amendment; automated AX is not spoken-output proof.
7. Full repair diff reviewed, current-source gates refreshed, fixture catalog and criterion/plan mapping synchronized. See the final evidence section below. Independent review/acceptance is not a worker decision.
